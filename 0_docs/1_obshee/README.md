# Раздел «Общее» (контент)

Структура такая же, как у «Администрирование» (`0_docs/2_admin/`), «Медкабинет» (`0_docs/3_medkabinet/`) и «Медадминистратор» (`0_docs/4_medadmin/`).

- **`articles/`** — статьи с префиксами `00–25` в имени файла; оглавление — `00_main.md` (ранее `user-guide.md`).
- **`images/`** — иллюстрации по одной подпапке на статью (`01_avtorizaciya-v-arm`, …). Внутри только файлы, без вложенных каталогов: скрины в тексте — `figure-01.png`, `figure-02.png`, … (порядок как в статье). Путь в Markdown: `/content/0_docs/1_obshee/images/<подпапка>/<файл>.png`.

Публичный URL страницы задаётся движком (часто совпадает с путём к `.md` без расширения).

Каталог **`images/obshee/`** в корне репозитория **не используется** для этого раздела после переноса. Служебные скриншоты плитки FAQ — в `images/25_chastye-voprosy/` (`faq-*.png`), описание — `README-faq-tile-screens.md` там же.
